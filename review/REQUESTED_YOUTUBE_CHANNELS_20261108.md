## 자동 수집 조건을 확인한 결과
창과 서버는 별도 프로세스다. Windows 예약 작업 KiwoomTop100Archive_2005가 로그인/09:15/17:15/20:05에 서버를 시작하며 Highest, 실행시간제한PT0S, Running 확인. 창이 닫혀도 이미 실행 중인 서버는 계속 작동한다. 이 작업은 대화형 로그인 상태에서 실행되며 PC전원/인터넷/서버/기능별 자동설정이 필요하다. 절전·종료 중에는 연속 수집되지 않는다.
상승률 상위 monitor, 거래량급증 monitor, 투자자 enabled, 추천 enabled는 모두 true 확인. 추천은 화면과 독립적인 서버 tick에서 주말 포함1200초(20분)마다 공개 자료를 확인한다. 상승테마는 상승률 수집 성공 후 갱신한다. 현재 당일 거래량 상위·당일 거래대금 상위는 volume-top.js의 화면 진입/1분 타이머에서 collect를 요청하는 예외로, 해당 화면을 닫으면 새 수집 요청이 생기지 않는다. 이번 채널 추가에서 이 두 기능의 실행 구조를 임의 변경하지 않았다.
