# 수집기 탭의 공통 원칙

사용자가 2026-10-26 지정한 기준이다. 기존 매매·주문 로직과 기존 수집기의 조건을 임의로 변경하지 않는다.

새 수집 탭을 추가하거나 기존 탭을 수정할 때 다음 기준을 적용한다.

1. 모든 수집기 화면에 동일한 전체 탭 메뉴를 표시한다. 창이 좁으면 줄바꿈하고 탭을 숨기지 않는다.
2. 순위·종목·기준 시각·수집 조건을 날짜별로 보관한다. 다른 날짜 자료를 오늘 자료로 표시하지 않는다.
3. 모든 종목에 소속 테마와 시가총액을 표시한다. 키움 테마·관심테마그룹·업종은 구분하고, 확인되지 않은 테마나 시총은 미확인으로 둔다.
4. 종목 프로필은 stock_profiles 공통 경로를 사용하고 날짜별 소속 정보와 당일 확인한 시총을 보존한다. 다른 날짜의 시총을 참고 표시할 때는 그 기준일을 함께 표시한다. 과거 소속을 현재 분류로 추측하지 않는다.
5. 종목 클릭 및 입력창 밖 ↑·↓ 키 이동은 수집기 차트와 선택한 영웅문 0600에 함께 연결한다. 입력창·선택상자·메모창 안에서는 키 본래 동작을 유지한다.
6. 1분봉·3분봉·5분봉·일봉·주봉을 제공한다. 기존 chart_data/chart_service의 조회·캐시·이동평균 계산을 재사용한다.
7. 영웅문은 기존 /api/hero-targets 및 /api/hero-link의 조회 화면 전용 경로를 사용한다. 연동 끄기·대상 선택 설정을 존중하고, 빠른 연속 이동은 마지막 선택을 우선한다. 주문·전역 키보드 입력 경로를 추가하지 않는다.
8. 기존 거래량 급증률·상승률·테마·수급 기능은 유지한다. 순위마다 별도 저장 폴더를 사용한다. 다른 순위의 자료를 덮어쓰지 않는다.
9. 새 탭을 공통 프로필 수집 대상에 등록한다. 테마·시총·날짜 보관·차트·클릭·화살표·영웅문 경로를 확인한 뒤 완료를 보고한다.
10. 실제 0600 화면의 종목 전환을 보지 못했다면 전송 경로 검사와 실제 표시 검증을 구분해 보고한다.

거래량·거래대금 상위100의 ETF·ELW·ETN 제외 조건은 유지한다. 새로운 종류의 순위에 같은 필터를 적용할지는 해당 요청의 조건에 따른다.
