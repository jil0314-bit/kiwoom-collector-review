다른 PC에서 같은 저장 자료 보기

1. 원본 PC, LG 노트북, 옆자리 PC에서 같은 Microsoft 계정으로 OneDrive에 로그인합니다.
2. OneDrive의 '상승률분봉수집기공유' 폴더를 '이 장치에 항상 유지'로 선택합니다.
3. 그 폴더에 도착한 '수집기설치.zip'을 바로 옆 '수집기설치' 폴더로 압축 해제합니다.
   예: OneDrive/상승률분봉수집기공유/수집기설치/공유수집기시작.cmd
4. '공유수집기시작.cmd'를 더블클릭합니다. 처음에 Python이 없다는 안내가 나오면
   안내된 python.org 공식 사이트에서 Python 3.13을 설치하고 다시 실행합니다.
   Pillow는 처음 실행할 때 설치됩니다.
5. 이후에는 같은 파일을 더블클릭합니다. 바탕화면에 이 파일의 바로가기를 만들어도 됩니다.

조회 범위
- 원본 PC가 공유한 상승률 순위, 분봉, 저장한 일봉/주봉, 관심종목, 메모,
  테마, 거래량 급증 자료를 같은 디자인으로 조회합니다.
- 원본 PC에서 아직 조회·저장하지 않은 차트는 자료 없음으로 알립니다.
- 동기화 자료의 가격은 저장 당시 가격입니다. 현재가나 틱 실시간 가격이 아닙니다.
- 원본 PC가 꺼져 있어도 OneDrive 자료가 다운로드된 PC에서는 마지막 자료를 볼 수 있습니다.
- 원본 PC가 꺼져 있을 때 새 자료는 수집하지 않습니다.
- 공유는 원본 PC → 다른 PC의 조회 방향입니다. 다른 PC에서는 공용 메모/테마 편집과
  중복 수집을 막습니다. 양방향 편집이나 노트북의 독립 실시간 수집은 이 설치본의 기능이 아닙니다.
- 영웅문 클릭/화살표 연결은 조회하는 PC에서 실행 중인 영웅문 0600을 대상으로 합니다.
  해당 PC의 영웅문 설치, 차트 대상 선택, 권한 일치가 필요하며 다른 PC에서 검증 전입니다.
- API 키, 계좌 설정, 자동매매 코드는 공유하지 않습니다.

동기화 기준
- 원본 PC 공유 작업은 5분 간격입니다. 다른 PC의 실행 중 수집기는 1분마다
  도착 여부를 확인합니다. OneDrive 전송 시간만큼 더 늦을 수 있습니다.
- 압축 자료와 해시가 모두 확인된 뒤에만 새 자료로 교체합니다.
  전송 중이거나 누락되면 이전 정상 자료를 유지합니다.
- OneDrive 공유 폴더를 다른 사람에게 공개하거나 공유 링크를 만들지 마세요.
- 현재 서버형 수집기를 외부 인터넷에 공개하지 않습니다.
