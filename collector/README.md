## 저장 방식 (2.0)

- 대시보드를 열거나 새로고침하면 오늘의 최신 상승률 순위와 분봉을 수집합니다. 같은 동작에서 10초 이내 중복으로 열린 탭은 한 번으로 처리합니다.
- **같은 날짜에는 마지막으로 수집에 성공한 자료 한 벌만 남습니다.** 오전 자료가 있어도 오후 수집이 완료되면 오전 자료를 삭제하고 오후 자료로 교체합니다.
- **새 자료 전체가 수집되기 전에는 이전 자료를 삭제하지 않습니다.** 실패하면 기존 자료를 유지하고 화면에 실패를 표시합니다. 수집 중에는 기존 완료 자료가 보입니다.
- 수집기는 장중 08:00~20:00에 **3분 간격**으로 새 순위와 그날 08:00부터의 분봉을 다시 수집합니다. 한 번 수집(100종목 약 2분)이 3분보다 오래 걸리면 끝난 뒤 다음 갱신을 진행하며 겹쳐 실행하지 않습니다.
- 20:00 이후 직접 저장한 자료는 최종으로 표시합니다. **20:05에 다시 최종 수집**하여 장중 자료를 교체합니다. 20:05 최종 수집 실패 시 15분 간격 최대3회 자동 시도합니다. 그 이후 직접 저장하면 그 마지막 성공 자료로 다시 교체합니다.
- 수집 중 ‘다시 갱신 예약’을 누르면 현재 수집 종료 후 한 번 더 최신 순위부터 받습니다. 여러 요청은 다음 한 번으로 합칩니다.
- **날짜가 다른 자료는 삭제하지 않습니다.** 과거 날짜는 조회만 하며 오늘 순위로 과거 자료를 바꾸지 않습니다.

대시보드를 열면 장중 자동 갱신이 켜집니다. ‘장중 자동 갱신 중지’로 중지할 수 있습니다. 진행 중 수집은 완료하며 20:05 최종 수집 예약은 유지합니다. 다시 대시보드를 열면 장중 자동 갱신이 켜집니다.
대시보드 창을 닫아도 백그라운드 수집기는 계속 실행됩니다. PC 종료 중에는 수집되지 않습니다.

PC를 꺼진 상태에서 켜는 기능은 없습니다. 주말에는 자동 수집을 건너뜁니다. 휴장 등으로 당일 분봉을 받지 못하면 기존 자료를 보존합니다.

## 조회와 보관

종목 보관함에서 날짜 → 종목 → 분 시각을 선택합니다. 시가=그 분 첫 가격, 고가/최고가=최대 가격, 저가/최저가=최소 가격, 종가=그 분 마지막 가격입니다. 장중 마지막 봉은 아직 진행 중일 수 있습니다.

차트 위에서 마우스를 움직이면 십자선·시각·가격·봉 정보가 표시됩니다. 클릭하면 해당 분을 선택합니다. 마우스를 누른 채 가로로 드래그해 3개 봉 이상 선택하면 그 구간이 확대됩니다. ‘이전 확대’로 한 단계씩 되돌리고, ‘전체 보기’ 또는 차트 더블클릭으로 전체 구간을 봅니다. 차트 오른쪽 ‘표시’에서 전체 / 최근 240봉 / 최근 120봉 / 최근 60봉을 고를 수 있습니다. 표시 봉은 그날 08:00 이후 저장분이므로 이른 시간에는 240봉보다 적을 수 있습니다. 확대 중에도 저장 데이터와 이동평균 계산은 바뀌지 않습니다.

봉 등락률은 `(종가/시가-1)×100`, 직전봉 대비는 `(종가/직전 저장봉 종가-1)×100`입니다. 전일 대비 상승률과 구분됩니다. 첫 저장봉은 직전 종가를 알 수 없어 직전봉 대비를 ‘—’로 표시합니다. 빈 분이 있으면 직전 저장봉은 정확히 1분 전이 아닐 수 있습니다. 화면의 정보창·선택한 분·표에 표시하며 원본 OHLCV 파일은 그대로 유지합니다.

`data/YYYY-MM-DD/latest.json`이 해당 날짜의 최신 자료 폴더를 가리킵니다. `snapshot-.../` 폴더에는 순위 CSV, 종목별 OHLCV CSV/JSON, 원본 응답 gzip, 수집 상태, SHA-256 manifest가 있습니다. 갱신 도중 새 임시 자료 폴더가 생기며, 성공하면 포인터를 한 번에 바꾸고 이전 폴더를 삭제합니다. 비정상 종료로 남은 임시 폴더는 다음 성공한 갱신 때 정리합니다. 파일 잠금/권한으로 이전 폴더를 삭제하지 못한 경우 화면에 삭제 보류를 표시합니다.

구버전의 `preview`/`final` 자료는 첫 성공 갱신 때 해당 날짜에 한해 교체·삭제합니다. 외부에 직접 내려받거나 내보낸 CSV/PNG는 독립된 파일입니다. 데이터를 보존하려면 `data` 폴더를 백업하세요.

PNG는 저장 데이터를 재구성한 차트이며 영웅문 원본 캡처가 아닙니다. API가 반환한 거래 분봉 순서로 표시하고 빈 분을 가짜 봉으로 채우지 않습니다. 이평선은 비수정 종가의 단순평균이며 이전 거래일 봉을 포함합니다. 영웅문의 수정주가·시장·이평 방식 설정에 따라 다를 수 있습니다.

## 데이터 범위

KRX+NXT 통합 상승률 상위100, ETF·ETN 제외, 양의 상승률입니다. 0181 화면 설정에 따라 목록이 다를 수 있습니다. 장중 한 번이라도 상위100에 들었던 모든 종목을 영구 보관하는 방식은 아닙니다.

순위는 각 수집 시작 시점 기준이고 분봉은 종목별 순차 조회 시점까지 받습니다. 정확히 같은 초에 모든 종목을 동시에 조회하지는 않습니다. 수신 첫/마지막 시각을 확인하세요. 100종목 저장 성공만으로 모든 시간대의 완전성을 보장하지 않습니다. 비거래·거래정지·NXT 대상 여부·API 미제공 시간은 분봉만으로 완전히 구분되지 않습니다.

인증정보는 기존 환경변수 또는 기존 인증 파일을 읽고 코드·로그·자료에 복사하지 않습니다. 토큰은 메모리에만 유지합니다. 주문 API는 사용하지 않습니다. 다른 PC로 옮기려면 Python 3.10 이상·Pillow·키움 인증 설정이 필요합니다.

## 차트 주기와 이동평균선 (2.2.0)

종목을 고른 뒤 차트 위 `1분봉 / 일봉` 버튼으로 전환합니다. 1분봉은 5·10·20·60·120·240분선, 일봉은 5·10·20·30·60·120일선을 표시합니다. 두 차트 모두 20·60선은 다른 선의 3배 굵기입니다. 십자선·클릭 선택·드래그 확대·이전 확대·전체 보기와 CSV/PNG 내보내기를 두 주기에서 사용할 수 있습니다.

분봉 이평선은 저장된 원본 응답의 이전 거래일 봉까지 사용하며, 원본 OHLCV·순위·수집/교체 스케줄은 바꾸지 않습니다. 60분선 등은 1분봉 60개 종가 평균입니다. 빈 분은 임의로 채우지 않으므로 실제 경과시간 60분과 다를 수 있습니다. 필요한 이력이 부족하면 해당 선은 빈값으로 표시합니다.

일봉은 `일봉`을 선택할 때 키움 조회 전용 API ka10081로 기준 날짜까지 별도 조회합니다. 최대 180거래일을 표시하고 그 이전 이력까지 이용해 120일선을 계산합니다. 비수정주가·KRX+NXT 통합 기준이며, 액면분할 등 가격 단절의 영향을 받을 수 있습니다. 장중 마지막 일봉은 진행 중일 수 있고 과거 장중 분봉 저장 시점의 일봉을 재현한 자료는 아닙니다. 조회 시각을 화면에 표시합니다.

조회한 일봉과 원본 응답은 `data/chart_history/YYYY-MM-DD/종목코드.json` 및 `.sha256`으로 별도 보관합니다. 당일 캐시는 5분 이후 다음 조회 때 갱신하며, 지나간 날짜의 장 마감 이후 캐시는 재사용합니다. 아직 조회하지 않은 종목의 일봉 최초 조회에는 키움 REST 연결이 필요합니다. 매일 100종목 분봉 수집과 별도로 동작합니다.


## 종목 메모와 키보드 이동 (2.3.0)

목록 오른쪽 위 삼각형에 커서를 올리면 선택한 날짜의 종목 메모를 봅니다. 삼각형을 클릭해 상승 이유·뉴스/공시 출처·개인 의견을 쓰고 `메모 저장`을 누르세요. 저장된 메모가 있는 삼각형은 진한 보라색입니다. 긴 메모는 미리보기 안에서 스크롤할 수 있습니다. 뉴스 자동 수집 기능은 아니며 확인된 사실과 추정을 구분해 직접 기록합니다.

메모는 `data/notes/YYYY-MM-DD/종목코드.json`에 저장합니다. 같은 날짜의 분봉 스냅샷 교체와 별도이므로 갱신·종료·재실행 후에도 남습니다. 다른 날짜는 별도 메모이며, 최대 20,000자입니다. 메모를 비우고 저장하면 내용을 지웁니다. 다른 창에서 먼저 저장한 메모를 덮어쓰려 하면 충돌을 알리고 작성 내용은 유지합니다. 저장 전 초안은 현재 창에서만 유지하며, 닫기 후 다시 열어도 복원됩니다.

입력창 밖에서 ↑·↓ 방향키를 누르면 현재 검색 결과의 저장된 종목을 순서대로 선택하고 차트를 바꿉니다. 맨 위·아래에서는 멈춥니다. 검색/메모 입력 및 날짜/봉 선택 중에는 방향키 본래 동작을 유지합니다. 종목 목록만 밝은 라벤더·민트 배색으로 변경했습니다.

## 영웅문 0130 관심종목과 주봉

종목 보관함 위 목록 종류를 `영웅문 0130 관심종목`으로 바꾸면 03~67번(01·02·05·07·08 제외), 98·99번 그룹을 영웅문 저장 순서와 구분 제목대로 볼 수 있습니다. 해당 PC의 확인된 0130 프로필 파일을 읽으며 영웅문 파일을 수정하지 않습니다. 종목명을 찾지 못한 항목은 코드를 표시합니다. 그룹을 바꾸거나 종목을 선택한 뒤 `1분봉 / 3분봉 / 5분봉 / 일봉 / 주봉`을 전환할 수 있습니다.

관심종목은 선택할 때 해당 날짜 차트를 별도 조회·보관합니다. 전체 관심종목의 분봉을 자동으로 일괄 수집하는 기능은 아닙니다. 기존 상승률 상위 100종목 자동 수집과 저장 폴더는 그대로 유지됩니다. 주봉은 키움 일봉을 월요일 시작 주간으로 합산한 비수정 차트이며, 5·10·20·30·60·120주선을 표시합니다. 20·60주선은 3배 굵기입니다. 해당 주의 거래가 끝나기 전에는 마지막 주봉 값이 달라질 수 있습니다.

### 테마 종목 직접 편집

- `자동으로 되돌리기`를 누르고 저장하면 그 테마의 편집이 모두 지워집니다.

카드 아래 `+ 새 테마 만들기`로 **내가 만든 테마**를 추가할 수 있습니다(최대 10개, 테마당 30종목). 이름과 종목을 정하면 담은 종목의 오늘 등락률 평균으로 카드가 만들어지고 평균 등락률 순으로 TOP 10 아래에 표시됩니다. 같은 차트 연동과 ↑ ↓ 이동을 그대로 씁니다.
