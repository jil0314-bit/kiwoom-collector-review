# 외국인·기관 순매수 일별 수집 계약

작성: 2026-10-18 / 범위: 조회·보관·화면 표시. 자동매매 판정/주문 변경 없음.

## 원본과 의미

- 영웅문4 0785에 해당하는 `ka90009` 외국인기관매매상위요청을 사용한다. 영웅문 GUI를 조작하거나 화면을 캡처해서 읽지 않는다.
- 명세와 [키움 공식 예제 저장소](https://github.com/Kiwoom-Securities/Kiwoom-REST-API)를 확인한 뒤 기존 표준 라이브러리 REST 어댑터를 사용했다. kwcli/추가 플러그인은 설치하지 않는다.
- POST `/api/dostk/rkinfo`, `mrkt_tp=000`, `amt_qty_tp=1`, `qry_dt_tp=1`, `date=YYYYMMDD`, `stex_tp=3`.
- `frgnr_orgn_trde_upper` 안의 `for_netprps_*`와 `orgn_netprps_*`가 서로 다른 두 목록이다. 같은 행 번호라고 같은 종목으로 합치지 않는다.
- 외국인: `for_netprps_stk_cd`, `_stk_nm`, `_amt`, `_qty`. 기관: `orgn_netprps_stk_cd`, `_stk_nm`, `_amt`, `_qty`.
- 금액은 **천만원**, 수량은 **천주** 단위의 API 정수다. 부호를 보존하고 절대값으로 바꾸지 않는다. 미제공 숫자는 JSON null / 화면 UNKNOWN / CSV 빈칸으로 남긴다.
- 응답에는 원본 기준 날짜가 없으므로 `source_date=UNKNOWN`이다. 요청 날짜와 수신 시각을 따로 저장한다. 날짜가 지정된 삼성전자 일봉의 당일 거래량이 양수인지 확인하여 휴장/미제공 의심 자료를 차단한다. 이것은 거래일 증거이며 순매수 응답의 날짜를 직접 증명하지는 않는다. 기준 종목의 거래정지/자료 미제공 시 수집이 보류될 수 있다.
- API가 제공한 금액순 목록을 보관한다. 상위 순매수 목록이며 전 종목의 총매수/총매도 전수 자료가 아니다. ETF·ETN을 임의로 제외하지 않는다. 영웅문 화면의 시장·거래소·금액/수량 설정이 다르면 목록이 다를 수 있다.

## 실행과 일정

`start.vbs → app.py → scheduler (5초 검사) → investor_flows.tick → start → refresh → Kiwoom.request`.

- 자동 수집은 기본 켜짐이며 켜짐/꺼짐은 `data/investor_flows/control.json`으로 재시작 후 유지한다.
- 실행 중인 평일 09:10~20:00에 10분 이상 간격으로 요청한다. 기존 Windows 시작 예약은 그대로 두므로 PC 시작/수집기 시작 시각에 따라 첫 수집이 늦을 수 있다.
- 20:00~20:05는 자동 수집을 쉬고 20:05 이후 한 번 더 요청한다. 이것은 마감 재조회이지 거래소 최종 확정값 보장이 아니다.
- 마감 재조회가 실패하면 15분 이상 간격, 최대 3회 시도한다. 시도 상태와 마지막 마감 재조회 성공은 디스크에 남아 재시작 후 중복을 억제한다.
- 수동 저장은 평일 09:10 이후 가능하다. 과거 날짜 수집/자동 소급수집/PC 깨우기/주말 수집은 하지 않는다.
- 자체 실행 잠금과 기존 상승률 수집기의 GUARD를 함께 획득하여 겹치는 상승률 작업을 피한다. 다른 독립 기능(거래량 급증 등)의 실행 구조는 변경하지 않는다. 기존 어댑터의 요청 간격과 재인증 처리를 유지한다.

## 저장과 실패 처리

- 별도 `data/investor_flows/YYYY-MM-DD.json`에 외국인/기관 순위, 요청·수신 시각, 요청 조건, 시장 응답 필드, 내용 SHA-256을 한 파일로 저장한다.
- 유효한 전체 연속조회가 끝난 뒤 고유 임시파일 → 원자적 rename으로 같은 날짜를 교체한다. 다른 날짜는 삭제하지 않는다.
- `cont-yn=Y`이면 `next-key`로 계속 읽는다. 누락/반복 키, 30페이지 한도 초과, 잘못된 숫자/코드, 충돌 중복, 전체 빈 응답, 날짜 변경, 파일 쓰기 실패 시 기존 정상 파일을 유지한다.
- 읽을 때 날짜와 SHA-256을 확인한다. 개인 정보·토큰·인증 헤더는 자료에 넣지 않는다. CSV의 시장 종목명은 수식 실행 방지를 적용한다.

## 화면과 공유

상단 외국인·기관 → `/investors`. 날짜, 종목 검색, 순위·금액·수량, 수신 시각과 기준일 미제공 안내, CSV를 표시한다. 데이터가 없으면 빈 상태로 표시한다. HTML을 동적으로 삽입하지 않고 textContent로 시장 문자열을 표시한다.

GET `/api/investors/status`, `/api/investors/day?day=...`, `/api/investors/csv?day=...`는 조회 전용이다. POST `/api/investors/collect`, `/api/investors/monitor`는 기존 Host/Origin/로컬 토큰 검사 뒤에만 동작한다.

기존 공유 자료/설치본 allowlist에 신규 모듈과 자료 폴더를 포함한다. 공유 조회 PC에는 스케줄러를 켜지 않고 버튼을 비활성화한다. GitHub에는 코드와 테스트만 공개하며 개인 수집 데이터는 올리지 않는다.

## 검증 범위

100개 오프라인 검사 통과. 신규 검사에는 두 목록 분리, 단위/부호/UNKNOWN, 연속조회/중복/오류, 원자적 교체 실패 보존, 다른 날짜 보존, 휴장·주말·자정, 해시 훼손, 20:05 판단과 재시작용 재시도 기록, 중복 실행, 오류 메시지 비밀정보 차단, HTTP 토큰·CSV가 포함된다. Python/JavaScript 문법과 브라우저 빈 상태 화면을 확인했다.

실제 ka90009 수신·영웅문 화면 수치 대조·다음 거래일 자동 저장 완료는 **UNKNOWN**이다. 2026-10-18 일요일 작업에서는 실제 키움 수집을 시도하지 않았다.
