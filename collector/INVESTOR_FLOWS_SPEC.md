# 외국인·기관 순매수 일별 수집 계약

작성: 2026-10-18 / 범위: 조회·보관·화면 표시. 자동매매 판정/주문 변경 없음.

## 원본과 의미

- 영웅문4 0785에 해당하는 `ka90009` 외국인기관매매상위요청을 사용한다. 영웅문 GUI를 조작하거나 화면을 캡처해서 읽지 않는다.
- 명세와 [키움 공식 예제 저장소](https://github.com/Kiwoom-Securities/Kiwoom-REST-API)를 확인한 뒤 기존 표준 라이브러리 REST 어댑터를 사용했다. kwcli/추가 플러그인은 설치하지 않는다.
- POST `/api/dostk/rkinfo`, `mrkt_tp=000`, `amt_qty_tp=1`, `qry_dt_tp=1`, `date=YYYYMMDD`, `stex_tp=3`.
- `frgnr_orgn_trde_upper` 안의 `for_netprps_*`와 `orgn_netprps_*`가 서로 다른 두 목록이다. 같은 행 번호라고 같은 종목으로 합치지 않는다.
- 외국인: `for_netprps_stk_cd`, `_stk_nm`, `_amt`, `_qty`. 기관: `orgn_netprps_stk_cd`, `_stk_nm`, `_amt`, `_qty`.
- 금액은 **천만원**, 수량은 **천주** 단위의 API 정수다. 부호를 보존하고 절대값으로 바꾸지 않는다. 미제공 숫자는 JSON null / 화면 UNKNOWN / CSV 빈칸으로 남긴다.
- 응답에는 원본 기준 날짜가 없으므로 `source_date=UNKNOWN`이다. 요청 날짜와 수신 시각을 따로 저장한다. 날짜가 지정된 삼성전자 일봉의 당일 거래량이 양수인지 확인하여 휴장/미제공 의심 자료를 차단한다. 이것은 거래일 증거이며 순매수 응답의 날짜를 직접 증명하지는 않는다. 기준 종목의 거래정지/자료 미제공 시 수집이 보류될 수 있다.
- API가 제공한 금액순 목록을 보관한다. 상위 순매수 목록이며 전 종목의 총매수/총매도 전수 자료가 아니다. ETF·ETN을 임의로 제외하지 않는다. 영웅문 화면의 시장·거래소·금액/수량 설정이 다르면 목록이 다를 수 있다.

## 실행과 일정

`start.vbs → app.py → scheduler (5초 검사) → investor_flows.tick → start → refresh → Kiwoom.request`.

- 자동 수집은 기본 켜짐이며 켜짐/꺼짐은 `data/investor_flows/control.json`으로 재시작 후 유지한다.
- 실행 중인 평일 09:10~20:00에 10분 이상 간격으로 요청한다. 기존 Windows 시작 예약은 그대로 두므로 PC 시작/수집기 시작 시각에 따라 첫 수집이 늦을 수 있다.
- 20:00~20:05는 자동 수집을 쉬고 20:05 이후 한 번 더 요청한다. 이것은 마감 재조회이지 거래소 최종 확정값 보장이 아니다.
- 마감 재조회가 실패하면 15분 이상 간격, 최대 3회 시도한다. 시도 상태와 마지막 마감 재조회 성공은 디스크에 남아 재시작 후 중복을 억제한다.
- 수동 저장은 평일 09:10 이후 가능하다. 과거 날짜 수집/자동 소급수집/PC 깨우기/주말 수집은 하지 않는다.
- 자체 실행 잠금과 기존 상승률 수집기의 GUARD를 함께 획득하여 겹치는 상승률 작업을 피한다. 다른 독립 기능(거래량 급증 등)의 실행 구조는 변경하지 않는다. 기존 어댑터의 요청 간격과 재인증 처리를 유지한다.

## 저장과 실패 처리

- 별도 `data/investor_flows/YYYY-MM-DD.json`에 외국인/기관 순위, 요청·수신 시각, 요청 조건, 시장 응답 필드, 내용 SHA-256을 한 파일로 저장한다.
- 유효한 전체 연속조회가 끝난 뒤 고유 임시파일 → 원자적 rename으로 같은 날짜를 교체한다. 다른 날짜는 삭제하지 않는다.
- `cont-yn=Y`이면 `next-key`로 계속 읽는다. 누락/반복 키, 30페이지 한도 초과, 잘못된 숫자/코드, 충돌 중복, 전체 빈 응답, 날짜 변경, 파일 쓰기 실패 시 기존 정상 파일을 유지한다.
- 읽을 때 날짜와 SHA-256을 확인한다. 개인 정보·토큰·인증 헤더는 자료에 넣지 않는다. CSV의 시장 종목명은 수식 실행 방지를 적용한다.

## 화면과 공유

상단 외국인·기관 → `/investors`. 날짜, 종목 검색, 순위·금액·수량, 수신 시각과 기준일 미제공 안내, CSV를 표시한다. 일별 화면·CSV는 외국인·기관 각각 코스닥 TOP 20과 코스피 TOP 20을 **20위→1위**로 표시한다. 수신 원본 25개는 삭제하지 않는다. 데이터가 없으면 빈 상태로 표시한다. HTML을 동적으로 삽입하지 않고 textContent로 시장 문자열을 표시한다.

기간 합산은 `data/investor_flows/periods/시작일_종료일.json`에 별도로 보관하며 날짜 선택 목록 맨 마지막에 표시한다. 외국인·기관은 각각 코스닥 TOP 30과 코스피 TOP 30이며 두 투자자의 금액을 서로 합치지 않는다. GET `/api/investors/period?start=YYYY-MM-DD&end=YYYY-MM-DD`, `/api/investors/period-csv?...`로 같은 저장 자료를 읽는다. 기간·해시를 검증하며 조회 화면에서 외부 API를 호출하지 않는다. 기간 순매수 수량을 수집하지 않았으면 UNKNOWN으로 보존한다.

GET `/api/investors/status`, `/api/investors/day?day=...`, `/api/investors/csv?day=...`는 조회 전용이다. POST `/api/investors/collect`, `/api/investors/monitor`는 기존 Host/Origin/로컬 토큰 검사 뒤에만 동작한다.

기존 공유 자료/설치본 allowlist에 신규 모듈과 자료 폴더를 포함한다. 공유 조회 PC에는 스케줄러를 켜지 않고 버튼을 비활성화한다. GitHub에는 코드와 테스트만 공개하며 개인 수집 데이터는 올리지 않는다.

## 검증 범위

오프라인 검사 범위에는 두 목록 분리, 단위/부호/UNKNOWN, 연속조회/중복/오류, 원자적 교체 실패 보존, 다른 날짜 보존, 휴장·주말·자정, 해시 훼손, 20:05 판단과 재시작용 재시도 기록, 중복 실행, 오류 메시지 비밀정보 차단, HTTP 토큰·CSV, 일별 역순 TOP 20·기간 TOP 30·기간 조회 경계가 포함된다.

2026-10-18 소급 조회에서 ka90009 과거일 응답을 수신했고, 2026-08-18~10-16의 삼성전자 일봉 거래일 40개를 보관했다. API는 원본 날짜를 반환하지 않으므로 source_date는 여전히 UNKNOWN이다. 영웅문 화면 수치 일치·다음 거래일 자동 저장 완료는 **UNKNOWN**이다.

## 2026년 과거 기간 합산 방법

요청 기간은 2026-01-01~08-17이다. 일별 상위 목록을 더하면 순위 밖 종목의 매매가 빠지므로 그렇게 계산하지 않는다. `ka10099` 현재 종목 마스터의 코스피·코스닥·ETF·ETN·리츠·인프라 목록에서 상장일이 기간 종료일 이후인 종목은 제외하고 중복 코드를 제거한다. `ka10058` 같은 기간 양 시장·양 투자자 순위에 등장한 코드도 합친다. 현재 마스터에 없고 기간 순위에도 등장하지 않은 상장폐지 종목까지 완전하게 복원했다고 보장하지 않는다. 이 범위를 자료의 coverage에 기록한다.

각 대상 코드의 `ka10061` 기간 합산(`stk_cd=코드_AL`, 시작·종료일, `amt_qty_tp=1,trde_tp=0,unit_tp=1`)에서 `frgnr_invsr`와 `orgn`를 읽는다. 응답 금액은 백만원이며 화면 천만원 값으로 10을 나눈다. 문자열 `--숫자`는 음수로 보존한다. 모든 대상의 성공 자료가 모인 뒤 각각 금액 내림차순으로 정렬해 TOP 30을 저장한다. 금액 동률은 코드 오름차순이다. 중간 캐시·원시자료는 GitHub에 올리지 않는다.

`ka10058`는 일부 기관 기간값이 날짜별 합과 달라 최종 금액 원본으로 사용하지 않는다. `ka10061` 표본은 `ka10059`의 날짜별 152거래일 합계와 대조했다. 삼성전자 기관은 8,473,582 대 8,473,581 백만원, 셀트리온 외국인은 1,935,286 대 1,935,282 백만원으로 반올림 차이가 있었다. 이는 표본 검증이며 모든 종목·기간의 정합성을 증명하지 않는다. 기간 응답도 원본 날짜가 없어 요청 기간과 원본 날짜 미제공을 구분한다.

시장별 소급 조회와 향후 자동 수집은 ka90009 mrkt_tp=001(코스피), 101(코스닥)을 각각 요청한다. 통합 상위 목록을 나누지 않는다. 각 시장의 양 투자자 목록 20개 이상과 두 시장 수신 성공 후 날짜별 자료를 교체한다. markets.001/101.rankings를 별도 저장하고 통합 원본도 보존한다. 일별 CSV는 두 시장과 양 투자자 합계 80행, 기간 CSV는 120행이다.

기간 분류는 ka10099 시장 0/10 마스터의 종목 코드로 확인하고 과거 ka10058 시장별 순위로 보완한다. 코드·시장 대응이 없는 종목은 UNKNOWN으로 보존하고 시장별 순위에서 제외한다. ETF·ETN은 기존 API 시장 분류를 유지하며 코스피 목록에 포함될 수 있다. 전체 금액 합계와 시장별 금액 합계를 혼동하지 않는다.

## 종목 선택·차트·0600 연동

외국인·기관 목록 오른쪽에 캔들·이동평균·거래량을 표시하며 좁은 화면에서는 차트를 위에 배치한다. 일별·기간·시장 구분을 유지한다. 클릭, Enter/Space, 위/아래 화살표, ↑↓ 버튼이 동일한 선택 경로를 사용한다. 검색 결과의 표시 순서대로 이동하며 입력·선택 상자·대화상자·한글 조합 중에는 종목 이동으로 가로채지 않는다.

기존 `/api/chart`와 `chart_data.load(source=watchlist)` 별도 조회 캐시를 재사용한다. `source=investor`는 날짜 또는 기간 종료일·시장의 저장 목록에 코드가 있는지 먼저 검증한다. 기본은 선택 날짜(기간 합산은 종료일)의 일봉이다. 분봉·3분봉·5분봉·주봉·현재 차트를 선택할 수 있다. 현재 차트는 15초 간격으로 갱신하며 미제공 봉을 만들지 않는다. 선택 버전을 확인해 이전 응답·예약 전송이 새 선택을 덮지 않게 한다.

영웅문은 기존 `/api/hero-link → hero_link.send`의 0600 전용 입력칸 경로를 유지한다. 대상 선택과 연동 끄기를 제공하며 모호하거나 닫힌 창에는 보내지 않는다. 테마 화면에도 같은 대상 선택기를 추가했다. 상승률 목록의 분봉 저장 대기 종목은 선택하면 목록 소속 확인 후 별도 현재 차트를 읽도록 보완했다. 수집 일정·순위·매매·주문·메모 처리는 변경하지 않는다.

관련 오프라인 검사 67개와 합성 자료 브라우저의 클릭·위아래·시장·기간·주기 전환 및 검증용 0600 코드 전달을 확인했다. 2026-10-18 인식된 실제 0600 창은 없었으므로 실제 영웅문 차트 화면 전환은 미확인이다. 전송 성공 표시와 실제 HTS 차트 갱신은 구분한다.
