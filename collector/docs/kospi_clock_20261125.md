# 코스피 연동 시계 (2026-11-25)

사용자가 기준 지수를 코스피로 선택했습니다.

- 모든 탭의 시계는 코스피 전일 대비 상승 시 빨강, 하락 시 파랑입니다. 보합/조회 대기/실패는 중립색입니다. 종목 자체 등락률과 혼합하지 않습니다.
- 시계 영역과 숫자의 가로 폭을 기존 대비 1.5배로 확장합니다. 글자 높이, 시계 높이, 1초 갱신은 유지합니다. 날짜 줄에 코스피 등락률을 표시하고 툴팁에 조회 기준을 표시합니다.
- 키움 조회 전용 `ka20001` (`mrkt_tp=0`, `inds_cd=001`) 요약을 사용합니다. 공식 규격과 예제를 확인했으며 시간별 이력은 필요하지 않아 연속조회하지 않습니다.
- `GET /api/market-index`는 공유 캐시를 반환하며 첫 조회/30초 경과 시 단일 백그라운드 작업만 시작합니다. 기존 시세 클라이언트와 인증·호출 제한을 재사용합니다. 90초 초과/날짜 변경/실패 상태는 상승·하락 색상으로 표시하지 않습니다. 응답에 원본 거래일은 없으므로 조회 시각을 거래일로 단정하지 않습니다.
- 순위/자동 수집/주문/0600 전송/개인 메모는 변경하지 않습니다. 인증정보나 지수 응답을 파일에 저장하지 않습니다.

검증: `python -m unittest test_market_index test_collector` 24개. `test_market_clock_ui.cjs`에서 8개 탭의 상승/하락/보합/실패/회복, 1.5배 폭, 기존 글자 높이, 모바일 가로 넘침 없음 확인. 기존 예약 작업으로 수집기만 재시작한 뒤 실제 코스피 응답과 운영 화면의 하락/파란색 일치를 확인했습니다. 운영 화면의 시계 폭 비율은 1.500배, 브라우저 오류는 없었습니다. 실제 주문이나 0600 조작은 시험하지 않았습니다.
