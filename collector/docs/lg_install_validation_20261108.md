# LG그램 독립 설치본 준비 (2026-11-08)

## 범위
새 설치 실행기(INSTALL_LG.cmd / setup_lg.ps1), 실행 바로가기, 초보자 설명서, 인증 설정 GUI, Windows 사용자별 DPAPI 저장을 추가했다. start.vbs/install_schedule.ps1/admin_restart.ps1은 폴더 내부 .venv가 있으면 그것을 우선 사용하며 없으면 기존 사무실 경로를 유지한다. 새 가상환경 폴더는 Git/ZIP에 포함하지 않고 설치할 노트북에서 생성한다. 수집·매매 조건, 주문 경로, 화면 디자인은 바꾸지 않았다.

## 보호 및 실행 정책
- 설치기는 다른 경로의 기존 예약 작업이 있으면 중지하며, 현재 경로라도 실행 중이면 재설치하지 않는다. 다른 관리자 Windows 계정으로 승격된 경우에도 중지한다. 기존 프로세스는 종료하지 않는다.
- 새 인증정보는 채팅·명령줄·로그·소스·ZIP에 넣지 않고 같은 Windows 사용자 범위 DPAPI로 암호화하여 LOCALAPPDATA/KiwoomCollector/credentials.dpapi에 저장한다. 새 노트북 설정에만 이것을 우선 적용하고 사무실의 기존 인증 탐색은 보존한다.
- 영웅문 사용자 폴더는 사용자가 지정하며, 노트북에서 미지정이면 기존 사무실 프로필을 임의로 읽지 않는다. 기본 시세·뉴스 수집에는 영웅문 로그인/설치가 필수는 아니다. 관심그룹·실물0600·메모는 노트북의 영웅문 설정이 필요하다.
- 노트북의 영웅문 파일 직접 메모 쓰기는 명시적0311/프로필 검증 전까지 꺼 둔다. 수집기 개인 메모와 상승 이유 표시는 별개다. 사무실 기존 쓰기 경로는 보존한다.
- Windows venv의 실제 자식 프로세스는 기본 Python 이미지로 나타남을 직접 확인했다. 재시작 도구는 작업/작업폴더/포트/실행 이미지/해당 app.py 명령줄을 확인한다. 임의 다른 프로젝트를 종료하지 않는다.
- 초기 설치는 자동 실행 예약을 등록하되 서버를 즉시 시작하지 않는다. 사용자가 허용IP 등록을 마친 후 실행한다. 향후 로그인 및 기존09:15/17:15/20:05 예약은 유지한다. 새로운 장애 재시작 정책이나 무인 전원 켜기를 추가하지 않았다.
- ZIP에는 실행 필수 Python/웹/아이콘/설정과 설치 안내/해시 manifest만 포함한다. 과거 수집 데이터·개인 메모·인증정보·캡처·로그·테스트·구버전·공유 보기 도구는 제외한다. 영웅문 메모 모듈의 필수 상위 파일 hero4_daily_memo.py / hero4_memo_import.py는 포함한다.

## 검증
- 기존201개 + 설치/암호화/사무실 기본 경로/노트북 메모 보호7개 = Python208개 통과.
- 별도 깨끗한 .venv에 설치본과 같은 Pillow13.0.0 설치 후208개 재검사 통과. 사무실 Python 패키지는 변경하지 않았다.
- Windows DPAPI 왕복 저장·해독 및 손상 거부를 가짜 시험 값/임시 폴더로 확인. 실제 인증정보는 검사에서 읽거나 저장하지 않았다.
- PowerShell 설치/예약/재시작3개 AST 문법 및 기존0600 JS 재시도 검사 통과.
- 사무실 예약 작업·프로세스를 재등록/종료/재시작하지 않았다. 설치기를 사무실에서 실제로 실행하지 않았다.
- 최종 ZIP은 별도 압축 해제 후 모든 manifest 해시, 필요 모듈 포함 및 실행 import/로컬HTTP를 검사한다. ZIP SHA256도 별도로 제공한다.

## 미확인 범위
LG그램 실물의 Python 설치, Windows UAC, 작업 예약 실행, 허용IP와 키움 인증, 실제 수집,0311 실물0600 전환, 영웅문 메모 쓰기는 미검증이다. Python3.13 시험 환경에서 검증했으며 안내하는 신규 Python3.14 환경과 LG그램에서의 설치 성공을 대신하지 않는다. 초보자 안내의 설치 완료와 실제 연결 성공을 구분한다. 오래된 사무실 자료와 사용자 메모를 자동으로 복사/동기화하지 않는다. 두 PC가 같은 앱키로 동시에 수집하는 구성은 권장하지 않는다.
