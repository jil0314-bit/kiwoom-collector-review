# 방송 코너·추천 분류 보완 (2026-11-27)

- MTN 오후장 작전타임의 이달해의 달달한 10분, 매일경제TV 조기준의 골든크로스를 공식 채널 ID로 구분하여 탐색한다. 검색은 최신순, 회당 최대 12개다.
- 기존 MTN 프로그램 공개 다시보기 및 두 방송사 공식 YouTube 채널 수집을 유지한다. MTN 프로그램별 공식 공개 기사 검색을 추가한다. 검색 실패·0건·자막 미제공은 완료로 숨기지 않는다.
- 신규추천, 관심종목, 기존추천·복기를 구분한다. 기본 목록에 세 분류를 함께 표시하며 개별 필터를 유지한다. 매도·상담·검수대기는 별도 분류다.
- 달달한 공략주 및 날짜가 붙은 과거 추천 성과를 서로 분리한다. 원문 과거 추천일을 보존하고 복기 방송일에 기록한다. 원추천일 미확인은 오늘로 대체하지 않는다. 게시일과 방송일·추천시각을 구분한다.
- 방송사 다른 영상에 코너명이 붙지 않도록 제목을 다시 확인한다. 제목·해시태그만으로 신규 추천을 생성하지 않는다. 자동 자막에서 오인식된 종목명은 추측해서 매핑하지 않는다.
- 기존 08:00~21:00 음성/OCR 금지 및 메모리 보호장치를 유지한다. 기사와 공개 자막 수집은 기존 주기로 실행한다.

## 검증

- Python 추천 수집 검사 43개, 메모리 보호 검사 5개, 직접 등록·메모 검사 7개 통과.
- 방송 화면의 신규/관심/기존추천 표시·필터, 오류 시 목록 유지, 반응형 화면 검사 통과.
- 공식 검색에서 두 코너 각각 12개 클립 발견. 오늘 두 영상은 기본 자막 응답이 비었지만 기존 공개 스크립트 보완 경로로 각각 127/82개 발언 구간을 읽었다.
- 자동 자막의 종목명 오인식이 실제 확인되었다. 모든 방송의 모든 추천을 빠짐없이 확인했다고 주장하지 않는다. 미확인 원문은 수집 현황에 남기고 다시 시도한다.
- 종목 차트·영웅문 클릭·주문 로직은 변경하지 않았다. 실제 0600 전환이나 주문 시험은 수행하지 않았다.
