# 공통 종목 등락률 표시 (2026-11-25)

- 모든 수집 탭의 종목명 옆과 차트 제목에 동일한 전일 대비 등락률 표시를 사용합니다. 양수 `+2.50%`, 음수 `-2.50%`, 보합 `+0.00%`이며 양수는 빨간색, 음수는 파란색입니다.
- 상승률/거래량/거래대금/테마 목록은 기존 목록에 담긴 주가 등락률을 사용합니다. 거래량 급증률이나 봉 시가 대비 수익률을 주가 등락률로 대체하지 않습니다.
- 수급/방송 추천/관찰종목 목록은 기존 `/api/quotes`를 사용합니다. `현재` 표식과 조회 기준 툴팁으로 과거 저장 목록과 구분합니다. 요청은 최대 10종목씩 순차 처리하고, 현재 창 내 값을 30초간 재사용합니다. 선택 차트에서 받은 현재 시세도 재사용합니다. 숨긴 창/공유 조회 화면에서는 추가 현재가 조회를 하지 않습니다.
- 차트 제목은 현재 차트의 quote를 사용합니다. 과거 차트는 해당 날짜의 저장 등락률이 있을 때만 표시합니다. 다른 날짜 값/현재 시세/봉 변동률을 혼합하지 않습니다. 미수신 값은 `등락률 미확인`입니다.
- API/수집/저장/주문/영웅문 전송 로직은 변경하지 않았습니다. 프런트엔드 표시와 기존 읽기 전용 시세 조회 재사용만 수정했습니다. 화면 새로고침으로 반영되며 서버 재시작이 필요하지 않습니다.
