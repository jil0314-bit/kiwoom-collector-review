LG그램 수집기 — 간편 설치

Python을 따로 설치하거나 명령어를 입력할 필요가 없습니다.

1. ZIP을 오른쪽 클릭 → 모두 압축 풀기
   LG그램의 일반 폴더에 풀어주세요. OneDrive·공유 폴더는 피하세요.
   압축 파일 안에서 바로 실행하지 마세요.

2. 1_처음설치.cmd 더블클릭
   '이 앱이 변경하도록 허용?' 창에서는 본인이 시작한 설치가 맞으면 '예'.

3. 키움 인증정보 입력 → 저장하고 설치 완료
   App Key / App Secret을 입력합니다. 계좌 비밀번호가 아닙니다.
   설정 창의 '키움 허용 IP 등록 페이지 열기'를 누르면 키움 페이지로 갑니다.
   로그인 → 계좌 APP KEY 관리 → IP 등록 현황에서 현재 나의 IP를 등록하세요.
   사무실 IP는 지우지 마세요.
   영웅문 폴더는 모르면 비워두어도 됩니다.
   설정을 마치면 수집기 화면이 자동으로 열립니다.

다음부터는 바탕화면 '수집기 - LG그램'을 더블클릭하세요.
또는 폴더의 2_수집기열기.cmd를 실행하세요.
설치 후 이 폴더를 옮기거나 지우면 실행되지 않습니다.

꼭 알아두세요
- 이 버전에는 Python3.14.10과 Pillow13.0.0 실행 환경이 포함돼 있습니다. 설치할 때 Python/Pillow를 따로 다운로드하지 않습니다.
- Windows10/11 64비트용입니다. 처음 관리자 허용이 필요하고, 수집에는 인터넷과 키움 허용 IP가 필요합니다.
- 집 Wi-Fi·사무실 Wi-Fi·핫스팟은 IP가 다를 수 있습니다.
- App Key/App Secret은 현재 Windows 계정으로 암호화해 LOCALAPPDATA/KiwoomCollector에 저장합니다. 채팅에 보내지 마세요.
- 같은 앱키라면 사무실과 LG그램에서 동시에 수집하지 않는 것을 권합니다.
- 사무실의 과거 자료·개인 메모·인증정보·연결 기록은 포함하지 않습니다. LG그램에서 새로 수집합니다.
- 로그인하면 서버가 자동으로 시작됩니다. 창을 닫아도 서버는 남지만, PC 종료·절전·인터넷 단절 중에는 수집하지 못합니다.
- 당일 거래량 상위·거래대금 상위는 해당 화면을 열었을 때 주기적으로 수집합니다.
- 0600 연결은 LG그램 영웅문에 끝자리0311 계좌로 로그인하고 차트 하나를 펼친 뒤 새로 확인해야 합니다.
- 영웅문 메모 파일 직접 쓰기는 계좌·폴더 확인 전까지 꺼져 있습니다. 수집기 메모와 상승 이유 표시는 별개입니다.
- '설치 완료'와 '실제 키움 연결 성공'은 다릅니다. 연결 오류와 마지막 정상 저장 시각을 확인하세요.
- LG그램 실물에서 설치·허용IP·실제0600 연동은 아직 확인하지 못했습니다.

키움 공식 안내: https://openapi.kiwoom.com/intro/serviceInfo
설치 오류가 나오면 오류 문구만 알려주세요. 인증정보는 보내지 마세요.
